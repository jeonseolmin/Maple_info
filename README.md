# Maple Info

메이플스토리 정보 검색 및 커뮤니티 플랫폼입니다.

## 주요 기능

- 넥슨 Open API 기반 캐릭터 정보 조회
- 캐릭터 장비 및 스탯 조회
- 게시판 및 댓글
- 실시간 채팅
- AI 챗봇
- 회원가입 및 로그인

## 기술 스택

### Backend

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Redis

### Frontend

- React
- Vite
- Axios
- React Router

### Infrastructure

- Docker
- Docker Compose
- Nginx
- AWS EC2
